# Launch assets

Made from a local build of main with `npm run launch-assets` (Playwright for the
frames and screenshots, Pillow for the GIF; no ffmpeg needed). Sample photos and
PDFs are generated by `scripts/make-launch-samples.*` so nothing personal is in
the images. Rendered with the Inter font so they match what Mac and Windows
users see (the site itself uses the system UI font).

| File | Use |
| --- | --- |
| `assets/network-tab.gif` | Product Hunt gallery slot 1, README, Reddit. 1270 by 760, 21 frames, about 10 seconds, 0.6 MB. Ten HEIC photos converting with the request panel open; ends on the hook line. |
| `assets/01-home.png` | Home page above the fold |
| `assets/02-merge-pdf.png` | Merge PDF with three documents loaded |
| `assets/03-sign-pdf.png` | Sign PDF: a typed signature placed on the signature line of page 3 |
| `assets/04-strip-exif.png` | Remove EXIF: what each photo revealed, then the lossless result |
| `assets/05-network-proof.png` | The request panel after a ten-photo batch: one request, the decoder, none carrying a file |
| `assets/06-install-prompt.png` | Alternate: the install prompt as it appears after a second run |
